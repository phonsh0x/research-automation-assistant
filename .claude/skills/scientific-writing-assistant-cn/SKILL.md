# scientific-writing-assistant-cn — 中文学术写作助手

## 角色定位

你是"中文学术写作助手"模块的开发者。基于本地文献库和课题组论文库，辅助课题组成员完成文献综述、基金申请书、学术论文和学位论文的撰写。

## 核心能力

### 1. 文献综述辅助

**输入：** 用户提供一个主题方向或几个关键词。
**输出：** 一段结构化的综述草稿，带引用标注。

流程：
1. 从本地文献库检索相关论文（通过 SQLite + RAG）。
2. 按时间线或方法论分类组织。
3. LLM 生成综述段落。
4. 自动插入引用标注：（作者, 年份）或 [编号]。

**示例输出：**

```markdown
## 2. 图像分割方法综述

### 2.1 传统方法
早期的图像分割方法主要基于边缘检测和区域生长...
（张三 等, 2018; Li et al., 2019）。

### 2.2 深度学习方法
2015 年，U-Net 架构的提出...
（Ronneberger et al., 2015）。
```

### 2. 基金申请书辅助

支持中文基金申请书常见模块：

| 模块 | 辅助内容 |
|------|---------|
| 立项依据 | 文献支撑、问题凝练、研究必要性论证 |
| 研究内容 | 目标分解、技术路线描述 |
| 研究方案 | 方法论证、可行性分析 |
| 特色与创新 | 基于课题组优势提炼创新点 |
| 研究基础 | 汇总课题组相关成果列表 |
| 预期成果 | 成果形式建议、量化指标 |

**特色：**
- 立项依据部分自动引用本地文献库中最新的关键论文。
- 技术路线部分可生成 ASCII 流程图或建议用 draw.io 补充。
- 基于课题组画像 (`research-group-profiler`) 提取课题组在该方向的积累，写入"研究基础"。

### 3. 论文章节辅助

- **摘要**：用户提供核心内容要点，助手生成规范的学术摘要（含目的、方法、结果、结论四要素）。
- **引言**：帮助构建"现状→问题→方案→贡献"的引言逻辑链。
- **相关工作**：自动从文献库检索相关工作，按主题分组。
- **方法**：辅助描述技术细节，确保术语一致。
- **实验结果**：辅助生成实验对比表格和分析文本。
- **讨论**：结合文献对结果进行讨论，提供可能的原因分析。
- **结论**：总结贡献，展望未来工作。

### 4. 文字润色与规范检查

- **语句通顺**：修正不通顺的中文表达、语病。
- **术语统一**：检查全文术语是否一致（如同一概念不要交替使用"图像分割"和"图片分割"）。
- **学术语气**：将口语化表达转为学术书面语。
- **参考文献格式**：检查引用是否完整、格式是否统一（GB/T 7714 或目标期刊格式）。
- **去重检查**：与本地文献库中的句子做相似度比对，警示潜在重复。

### 5. 引用推荐

当用户在写作中提到一个观点但没有引用时：

1. 从本地文献库检索最相关的论文。
2. 推荐 3-5 条引用，标注相关度和理由。
3. 用户可一键插入引用或忽略。

## 写作风格要求

### 中文学术写作规范

- 遵循学术论文通用写作规范，语言严谨、逻辑清晰。
- 避免使用"非常"、"很"、"特别"等口语化程度副词，改用"显著"、"较为"、"明显"。
- 避免使用"我们"的过度使用—在描述方法时可用被动语态，在强调贡献时可用"本文"。
- 专业术语首次出现标注全称和英文，如 "生成对抗网络 (Generative Adversarial Network, GAN)"。
- 公式、图表编号统一（图 1、表 2、式(3)）。
- 数字和单位之间留空格（如 "5 mm"，非 "5mm"）。

### 针对硕士论文

- 综述章节按"概念定义→方法分类→优缺点比较→发展趋势"结构。
- 方法章节按"总体框架→模块 1→模块 2→...→模块间关系"结构。
- 实验章节包含"实验设置→数据集→评价指标→对比实验→消融实验→结果分析"。

## 系统提示词概要

```
你是一位中文学术写作专家，服务于某高校计算机/人工智能课题组。
你的任务是基于本地文献库协助撰写学术论文。

原则：
1. 所有引用必须来自本地文献库，不得编造。
2. 中文输出，学术书面语风格，语言严谨。
3. 保持客观，不使用过度宣传性语言（如"革命性"、"最佳"）。
4. 当不确定时，标注"建议进一步查证"。
5. 引用格式：中文文献用（作者, 年份），英文文献用 (Author, Year)。
6. 对硕士论文写作，用简洁明快的风格，不堆砌修辞，重逻辑清晰。
```

## 与其他模块的协作

## 安全与学术诚信

- 所有生成的内容为**草稿辅助**，最终需由人工审核和修改。
- 不得代为撰写论文核心创新部分（属于学术不端）。
- 生成内容如与已有文献高度相似，应提示用户改写。
- 引用必须真实存在，不可虚构文献。

## 输出风格

- 中文输出，学术书面语，符合硕士论文/基金申请书的行文规范。
- 逻辑清晰，段落分明，小标题层次合理（不超过三级）。
- 提供的内容标注草稿性质："[以下为 AI 辅助生成的草稿，请核实修改]"

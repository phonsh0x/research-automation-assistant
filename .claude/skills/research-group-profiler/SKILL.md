# research-group-profiler — 课题组论文方向画像

## 角色定位

你是"课题组论文方向画像"模块的开发者。负责分析课题组已发表的论文集合，自动提取研究方向、方法和领域标签，生成可视化报告，帮助课题组了解自身研究特色和演化趋势。

## 核心功能

### 1. 课题组论文管理

- 标记论文：用户可手动或通过脚本将论文标记为 `is_group_paper = 1`。
- 导入课题组已发表论文：支持从 BibTeX、RIS、Google Scholar Profile、ResearchGate 或手动录入导入。
- 支持按成员筛选：如"只看导师的论文"或"博三学生的论文"。

### 2. 研究方向自动抽取

对课题组论文的标题、摘要、关键词进行：

1. **TF-IDF / TextRank 关键词提取** — 中英文分别处理，提取有区分度的术语。
2. **Topic Modeling** — 使用 BERTopic 或 LDA 发现隐藏的主题簇。
3. **LLM 辅助分类** — 调用 DeepSeek-V4-Pro 对每篇论文打方向标签（如"计算机视觉→医学图像分割→半监督学习"）。
4. **人工校正** — 提供界面让课题组成员修正自动标签。

### 3. 画像指标

| 指标 | 说明 |
|------|------|
| 研究方向分布 | 各研究方向的论文数量和占比（饼图/柱状图） |
| 方法标签分布 | 课题组常用方法（如 "Transformer", "CNN", "GAN"）的频次 |
| 主题演化 | 各方向论文数量随时间的变化趋势（折线图） |
| 合作网络 | 合作者共现网络图（力导向图） |
| 期刊/会议偏好 | 论文发表的期刊和会议分布 |
| 引用分析 | 课题组论文被引统计，高被引论文标记 |
| 关键词云 | 论文关键词的词云图（中英文分别或混合） |
| 跨学科度量 | 论文引用参考文献的学科多样性指数 |

### 4. 合作者网络构建

从 `paper_authors` 表中提取课题组作者，构建合作网络：

```
节点 = 作者
边 = 合著关系（权重 = 合著次数）
```

输出：
- 合作网络 JSON（用于 D3.js 或 vis.js 可视化）
- 中心性指标（度中心性、介数中心性）
- 识别核心合作者和外部合作者

### 5. 趋势分析

- 按年份统计各方向论文数量。
- 识别"上升趋势"（近 3 年增长的方向）和"下降趋势"（近期减少的方向）。
- 方法与技术的演化路径（如：CNN → ResNet → ViT → SAM）。

### 6. 对比分析

与全球同领域论文进行对比（通过 OpenAlex 或 Semantic Scholar 获取领域统计数据）：
- 课题组研究方向是否与全球热点一致
- 课题组方法选择的独特性
- 期刊发表层级对比

## LLM 辅助分析 Prompt

```
你是一位科研方向分析专家。以下是课题组的论文摘要和关键词列表。
请分析：
1. 课题组的主要研究方向（3-5 个，按重要性排序）
2. 每个方向的代表性论文（1-3 篇）
3. 课题组的方法特色（3-5 个独特技术优势）
4. 未来 2-3 年可能的扩展方向

论文列表：
...
```

## 可视化输出

使用 `matplotlib`、`plotly` 或 `echarts` 生成图表：

| 图表类型 | 内容 | 推荐工具 |
|---------|------|---------|
| 饼图/环形图 | 研究方向占比 | plotly |
| 折线图 | 论文数量趋势 | matplotlib/plotly |
| 词云图 | 关键词频率 | wordcloud |
| 力导向图 | 合作网络 | pyvis/networkx + D3.js |
| 热力图 | 方向×年份交叉统计 | seaborn |
| 桑基图 | 主题演化流 | plotly |

## 报告生成

生成一份中文 Markdown 课题组画像报告，包含：

1. **概览** — 论文总数、时间跨度、人均产出、h-index 等
2. **研究方向** — 各方向描述 + 图表
3. **方法特色** — 常用方法总结
4. **合作网络** — 课题组合作图谱
5. **发表分析** — 期刊/会议偏好、引用统计
6. **趋势与建议** — 基于数据的未来方向建议

报告输出到 `data/profiles/report_{timestamp}.md`。

## 定时更新

- 建议每月重新运行 profiler 更新画像数据。
- 当有新论文入库并标记为课题组论文时，自动增量更新画像。

## 输出风格

- 中文报告，带可视化图表。
- 结论有数据支撑，避免空泛评价。
- 趋势分析需慎重，标注是"数据驱动推断"还是"课题组内部共识"。

# `.claude/` — AI 协作配置（可选）

本目录保存项目开发期使用的 **agent 定义** 与 **skill 规范**，供 Claude Code 等支持该约定的
AI 编程助手自动加载。它们**不是运行时代码**，删除后不影响 `python run.py` 的任何功能。

## 内容

| 目录 | 数量 | 用途 |
|---|---|---|
| `agents/` | 8 | 架构师、文献检索、PDF→Markdown、RAG、画像、写作、SQLite、QA 测试等角色定义 |
| `skills/` | 7 | 对应模块的实现规范（数据模型、接口约定、验收标准） |

## 重要说明

1. **这是设计阶段的原始文档**，其中出现的模块名（如 `paper_download`、`pdf_to_md`）是早期设计词汇，
   最终代码中的目录名是 `src/fulltext/`、`src/pdf_converter/`。阅读时请以 `README.md` 的目录结构为准。
2. **不含任何密钥、账号或本机路径**，可安全公开。
3. `settings.local.json`、`*.local.md` 等个人本地配置**不会**被提交（见根目录 `.gitignore`）。
4. 若你使用其他 AI 工具，可忽略整个目录，或把 `skills/*/SKILL.md` 当作模块设计文档阅读。

## 为什么把它放进仓库

一份"AI 辅助的工程实践"记录：需求如何被拆成模块、每个模块的验收标准是什么、
测试角色如何定义。它展示了从设计规范到可运行代码的映射过程。

# v0.3.0 — 首个公开版本

这是 **research-automation-assistant** 的首个公开版本。

本项目定位为一个**本地优先的科研文献自动化流水线**，主要用于简化科研文献检索、合法全文获取、PDF 处理、本地文献管理等工作。

## 主要功能

### 多源文献检索

目前支持从多个公开学术数据源检索并聚合文献：

- OpenAlex
- Crossref
- PubMed
- Europe PMC

检索流程目前包括：

- DOI 去重
- 元数据整合
- 检索历史记录
- 期刊监控
- 基础标题弱去重

### 合法全文获取

项目支持通过多个合法渠道解析和获取可公开访问的论文全文，包括：

- Unpaywall
- PubMed Central
- arXiv
- 出版社开放获取资源
- 机构访问流程支持
- 用户手动上传 PDF

项目明确禁止并拦截：

- Sci-Hub
- LibGen
- 盗版镜像
- 绕过付费墙
- 验证码绕过
- 未授权账号访问

项目的目标是在合法、合规的前提下完成科研文献获取和管理。

### PDF 转 Markdown

可将本地科研论文 PDF 转换为结构化 Markdown，用于后续处理。

当前流程包括：

- PDF 文件管理
- 后台转换任务
- Markdown 输出管理
- 转换状态追踪
- Streamlit 转换界面

目前尚未实现：

- OCR
- 高级图表识别
- 完整参考文献解析
- 高精度公式结构恢复

### 本地科研文献库

项目使用 SQLite 管理本地科研文献数据。

目前支持：

- 论文元数据存储
- 作者信息管理
- 关键词管理
- 检索历史
- 全文获取状态
- PDF / Markdown 文件路径管理
- 文献统计
- BibTeX 导出

运行时产生的：

- 数据库
- PDF
- Markdown
- 日志
- 本地配置
- API Key

均不会提交到 Git 仓库。

### Streamlit 图形界面

当前包含 9 个主要页面：

- 系统概览
- 文献检索
- 本地文献库
- 全文获取
- PDF 转换
- RAG 智能问答
- 课题组画像
- 科研写作辅助
- 系统设置

其中部分页面属于未来功能入口，目前尚未完成对应核心功能，项目文档中已明确标注。

### FastAPI 接口

项目提供 FastAPI 后端接口，用于支持主要文献管理和 PDF 转换流程的程序化调用。

## 当前真实完成度

**文献检索 → 合法全文获取 → PDF 转 Markdown → SQLite 本地文献库 → BibTeX 导出**

以下功能仍处于开发阶段。

接下来的重点包括：

- DOI 规范化

- 去重策略统一

### 测试体系

- 使用独立临时数据库
- 加强 API 测试
- 增加关键业务流程回归测试
- 改进测试隔离

### 架构重构

- 增加统一的 Service Layer

- 拆分大型 Repository
- 改进数据库事务和连接管理

### RAG 全链路

逐步实现：

**Markdown → Chunk → Embedding → Vector Store → Hybrid Retrieval → Rerank → Context → LLM → Citation**

## 项目原则

本项目优先考虑：

**功能正确性 > 稳定性 > 性能 > 可维护性 > 代码简洁程度**

不会为了减少代码、依赖或 Token 消耗而明显牺牲功能质量、准确性或性能。
